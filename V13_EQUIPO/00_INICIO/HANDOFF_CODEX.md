# Prompt para Codex — investigación y reconstrucción independiente

Analiza este expediente V13 del módulo Equipo de Fresha y, por separado, el paquete acumulado V12 para otras áreas. No supongas que el sistema interno de Fresha es accesible. Reconstruye un mapa de requisitos **a partir de la evidencia observable** y diseña una implementación original.

Tu primera misión es leer los hallazgos y fotogramas, distinguir `VERIFICADO`, `OBSERVADO`, `SOLO INTERFAZ`, `INFERIDO` y `PROPUESTO`, y elaborar: diagrama de entidades, modelo transaccional de comisiones/nómina, matriz de permisos propia, pruebas de idempotencia, calendario de turnos y especificaciones de UX.

No programes a ciegas. Antes de implementar, publica una matriz de incertidumbre. Presta especial atención a la distinción entre `pagar manualmente` y realmente transferir fondos. No copies código ni identidad gráfica de Fresha.
