# Accesibilidad y estructura
E02–E11 son árboles de accesibilidad del navegador, NO HTML completo ni DOM serializado. Recogen jerarquías, roles, nombres, valores, IDs de controles y rutas renderizadas.
Observado: navegación enlaces; grupos pestañas; contenedores; inputs texto; textarea; stepper; switches; botones expuestos como checkbox en esta herramienta; popups; asistentes con progreso.
No interpretar cada rol checkbox como checkbox HTML real. IDs react-aria sugieren uso de componentes de accesibilidad React Aria, pero no prueban framework, versión o dependencias instaladas.
No exportado HTML, estilos computados, bundles, source maps, red o estado interno. La investigación se restringió a capacidades UI ya disponibles.
