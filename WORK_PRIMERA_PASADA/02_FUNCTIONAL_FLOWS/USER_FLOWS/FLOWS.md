| Cliente y cita | Alta cliente → validación vacío → guardar ficticio → seleccionar servicio/equipo/hora → guardar | Cita reservada | E01 |
| Venta | Cita → finalizar compra → carrito → propina → pago → descartar | Borrador descartado, sin cobro | E01 |

## Efectos no probados
Cambiar servicio/precio después de reservar; eliminar empleado; cancelar tras cobrar; ajuste parcial; impuestos; redondeo; timezone/verano; consumo de cupón concurrente; mensajes al reprogramar; stock y comisiones.
