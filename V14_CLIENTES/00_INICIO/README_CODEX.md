# FRESHA | módulo Clientes, Segmentación y Reputación | V14

**Fuente:** grabación original del 18-nov-2026, duración 100.6 segundos (1440×772). Evidencia capturada con acceso de prueba autorizado a interfaz de Fresha, sin acceso a su backend.

Este ZIP es un módulo de evidencia; **no es código fuente de Fresha**. La sección `01_VIDEO` contiene el original; `02_CAPTURAS` muestra momentos significativos; `03_DOCUMENTACION` registra hallazgos, flujos y limitaciones; `04_MATRIZ` vincula cada afirmación a tiempos y estados.

## Uso por Codex
1. Lee `03_DOCUMENTACION/HALLAZGOS_VERIFICADOS.md` y `04_MATRIZ/COBERTURA.csv`.
2. Mira el video antes de inferir funcionamiento de secciones que solo muestran estados vacíos o un complemento sin activar.
3. Separa hechos observados de hipótesis y propuestas de implementación original.
4. Documenta entidades conceptuales Cliente, Segmento, Criterio, Reseña y relaciones **solo como propuestas**, no como esquema interno real de Fresha.
5. Implementa independientemente y prueba contra flujos verificables; no copies diseño propietario ni código protegido.

## Aclaración de alcance
El video muestra un **guardado de edición de segmento** confirmado por la interfaz; no verifica que clientes de prueba pasen a integrar el segmento, ni segmentaciones masivas, ni comunicaciones automáticas. El módulo fidelidad muestra una invitación a activar un complemento, no un programa funcionando. El módulo reputación muestra cero reseñas y un acceso a conectar Google, no una integración completada.
